# Dragon Quest VI English Patch (Pegazaru version)
## Premise
This is an English patch of Dragon Quest VI. It is a complete overhaul of the old NoPrgress fan translation that uses the old patch as a base. All scenario dialogue, battle text, item names, monster names, and skill & spell names have been modified. 

You can find more information about the project [here at https://cleartonic.net/dq6/](https://cleartonic.net/dq6/).

## Instructions
- Head to the [Releases](../../releases) page and download the latest .ips patch.
- Acquire an unheadered Japanese ROM of Dragon Quest VI
- Use a patching program such as [Lunar IPS](https://www.romhacking.net/utilities/240/) to apply the patch

## Important information
- No gameplay elements have been modified with this patch  
- Message speeds 1 and 8 result in faster scenario text:  
  - In the Japanese version, message speed only affects text in battles. In this version, message speed will also affect text out of battles. There are now two text speeds for dialogue that are affected by your message speed. When setting message speed, both speed 1 and speed 8 will result in faster dialogue text speed  
    - For some extra context, text speed 8 is a "manual" text advance mode for battles, which often turns out to be faster with mashing/turbo. This is why setting text speed 8 will also yield faster dialogue
